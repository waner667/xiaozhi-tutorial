| | |
|---|---|

## 每篇教程都遵守的三条规矩

### 一、按动手顺序写，不按知识结构写

读者是跟着做的，不是来读论文的。所以每篇的主线都是同一条：

```
看成品 → 备材料 → 接线 → 烧录 → 配网 → 验收 → 卡住了查常见问题
```

原理分析、架构讨论、踩坑复盘**全部推到文末附录**，不打断主线。

### 二、每一步都有可验证的判据

不写"应该可以了"，写"你应该看到这一行"：

- 编译成功看 `Successfully created ESP32-C6 image.`，不看退出码
- 舵机接对看开机那行 `0deg=26214 90deg=78643 170deg=125199`
- 屏幕正常等 5 秒后亮，3 秒内不亮不代表坏了

### 三、买错的东西要提前说

- OLED 必须买**四脚 I2C**，不是七针 SPI —— 买错插上去毫无反应
- 舵机必须买 **180° 限位版**，不是 360° 连续旋转版
- 板子必须认准 `bread-compact-c6`，换型号引脚表不能照抄

## 贯穿三篇教程的一条原则

**先拿到物理事实，再动手。**

所有排查的第一步都是**让固件自己把状态打印出来**，而不是先换线。
一次烧录换来对所有引脚的确定性认知，成本几分钟；
反过来，先入为主地改硬件，代价是几小时甚至白拆几轮。

本套教程里有八次真实的误判，全部指向"硬件坏了"，
最后全部被一行日志或一次测量推翻。

具体案例见 [③ 外设不工作怎么查](site/03-troubleshooting.md) 的「反面教材汇总」。
