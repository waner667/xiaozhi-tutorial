## 贯穿三篇教程的两条原则

### 原则一：先拿到物理事实，再动手

所有排查的第一步都是**让固件自己把状态打印出来**，而不是先换线。

一次烧录换来对所有引脚的确定性认知，成本几分钟；
反过来，先入为主地改硬件，代价是几小时甚至白拆几轮。

### 原则二：软件 bug 会完美伪装成硬件故障

本套教程里有三处真实的误判，全部指向"硬件坏了"，
最后全部被一行日志或一次测量推翻。

所以任何时候出现"它有电、有响声、就是不工作"——
**优先怀疑软件**（单位、量纲、配置），而不是线没插好。

具体案例见 [③ 外设不工作怎么查](site/03-troubleshooting.md) 的「三次误判」。
