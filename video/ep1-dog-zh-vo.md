# 小智机器狗 · Ep1 口播稿（中文版 · 分享版）

> 配套《小智机器狗 · Ep1 拍摄脚本》使用。  
> **分享视频，不是教学视频**：讲"我做了什么、长什么样"，不要求观众跟着做对。  
> 括号里是动作/画面提示，不念。

---

## 基本信息

| 项   | 值                                    |
| --- | ------------------------------------ |
| 时长  | **1:25**（念白 0:44 + 动作停顿与看图时间）        |
| 语速  | 正常偏慢，约 4.5 字/秒                       |
| 字数  | **197 字**（`_count_vo.py` 实测，纯念 44 秒） |
| 语气  | 分享。像给朋友看手机里的视频，边说边指                  |
| 出镜  | 正面出镜，手里拿着实物讲                         |
| 不出现 | "关注我""点赞""订阅"；也不出现"我教你""跟着做""很简单"    |

**流程一共五步**：材料 → 照图接好 → 接好的样子 → 烧固件 → 好了。

**接线一个字都不讲。** 不解释哪根线去哪、为什么这么接。画面放一次电路图，  
一句话带过，然后就展示接好的样子——观众要看的是结果，不是接线过程。

---

## [00:00] 段0 · 开场（8 秒）

（出镜。桌上零件摊开，四条腿的支架放最前面）

> 这是机器狗，今天做一个简单的教学。

## [00:08] 段1 · 材料（20 秒）

（出镜。手边逐件点过去，不快）

> 用到的就这些：一个 ESP32-C6，一块 OLED 屏，麦克风、功放、喇叭，  
> 四个舵机，两块 400 孔的面包板。
>
> 再加一个降压模块和一个电源给它供电。

（拿起一个舵机，转侧面）

> 舵机我买的是 **180 度版**。

---

## [00:28] 段2 · 照图接好（16 秒）

（**切全屏电路图**，停住不动）

> 怎么接我就不讲了，照这张图接的。如果你稍微懂一点面包板的原理，半个多小时接完。

（图停 6 秒，不配旁白）

---

## [00:44] 段3 · 接好的样子（12 秒）

（**空面包板图** → 切**装好的图**，同机位同角度）

> 左边是杜邦线图，右边是接好的。

---

## [00:56] 段4 · 烧固件（18 秒）

（出镜拿 USB 线 → 切录屏，工具已打开。录屏操作这段可以 1.5× 加速）

> 接好之后，我们就把固件烧录到开发板中。

---

## [01:14] 段5 · 好了（11 秒）

（中景，手放电源开关上，打开。四条腿自己站起来。**一镜到底**）

> 烧完，打开电源。
>
> 它自己站起来了。

（停 2 秒，让它做完动作）

> 到这儿就成了。

## 中英术语对照（出英文版直接用）

| 中文            | 英文                                |
| ------------- | --------------------------------- |
| 舵机            | servo                             |
| 180 度版 / 连续旋转 | the 180 one / continuous rotation |
| 接线图           | wiring diagram                    |
| 降压模块          | buck converter                    |
| 面包板           | breadboard（400 孔 = half-size）     |
| 杜邦线           | jumper wires                      |
| 固件 / 烧录       | firmware / flash it               |
| 一体包           | a single merged image             |

## 录制提醒

- **别念稿**。记住每段一句核心话，其他用自己的话说。
- **看镜头**，一句话的结尾尤其要看镜头。
- **手里有东西**：讲舵机拿舵机，讲面包板举面包板。
- **电路图那段别抢话**。图一放上去就闭嘴，让画面停够 4 秒——这 4 秒比多说十句有用。
- **站起来的镜头别剪碎**，也别配 BGM。
