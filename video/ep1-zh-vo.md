# 小智 AI · Ep1 口播稿（中文版）

> 主版 3:30 / 短版 90 秒。配套《小智 AI · Ep1 拍摄脚本》使用。
> **这是内容基准稿**：台词定死之后，英文版按同一骨架重写（不是逐句直译），语感按英文重新组织。
> 括号里是动作提示，不念。

| 项 | 值 |

## [00:00] 段0 · 钩子（10 秒）

> 桌上这五个零件，加起来不到八十块。
>
> 半小时之后，它们会变成一个能跟你说话的东西。
>
> 今天不讲原理，就一件事——怎么把它们接到一块儿。

（画面：俯拍五个零件摊开。最后一句说完，手伸进画面拿起面包板）

---

## [00:10] 段1 · 认零件（28 秒）

> 先认人。不认清楚，线一定会插错。
>
> 这块白色的、带金属罩的，是 ESP32-C6。唯一的大脑，别的都插在它旁边。
>
> 这块黑的、四个脚的小屏，是 OLED。它的脸。
>
> 这个带小孔的，麦克风，INMP441。负责听。
>
> 这块黑绿色的小板，功放，MAX98357A。负责吼。
>
> 最后，喇叭。四欧，三瓦。
>
> 没了。就这五件。

（手指逐个点过去，每点一个停 1 秒。点"喇叭"时可以把喇叭拿起来晃一下）

> 💡 **别在这里解释每个模块怎么工作。** 这一集只回答"这是谁"。想讲原理留到 Ep6。

---

## [00:38] 段2 · 认面包板（20 秒）

> 接线之前，先看这块板子。这一分钟看完，后面全顺。
>
> 中间这条沟，把左右两边彻底隔开——左边的孔，和右边的孔，不通。
>
> 但是竖着一列，五个孔，是连在一起的。
>
> 记住这两句就够了：凹槽两边不通，同一列五个孔相通。
>
> 我接错的第一个原因，就是忘了这句。

（手把面包板沿凹槽折一下再合上，让观众"看见"断开）

---

## [00:58] 段3 · 接屏（32 秒）

（右上角接线表是高亮的常驻图形层，后面几段一直在）

> 先接屏，四根线。
>
> VCC 到 3V3，GND 到 GND。这两根好说。
>
> 坑在这两根：SDA 接 GPIO11，SCL 接 GPIO10。
>
> 我知道你在想什么——是不是反了。我也这么以为。这块板子偏偏就是 SDA 在 11、SCL 在 10。
>
> 而且这两个脚挨着，插反了不会报错，不会冒烟，就是黑屏。黑得让你以为是屏坏了。
>
> 所以别凭左右猜。对着屏上印的字，一个字一个字对。

（特写：屏背面的丝印 `SDA` `SCL`，手指点两下）

---

## [01:30] 段4 · 接麦克风（32 秒）

> 麦克风，五根。
>
> VDD 和 GND，照旧，3V3 和 GND。
>
> 剩下三根是数据：SCK 走 GPIO5，WS 走 GPIO4，SD 走 GPIO6。
>
> 注意这个 SD。它不是内存卡，是这根线的数据脚。名字取得很洋气，位置就差一个数——6，不是 5。
>
> 接完先别急着往下。这三根插实一点，面包板接触不良很常见。

（画面：手把三根线往里按一下，线不动了）

---

## [02:02] 段5 · 接功放和喇叭（50 秒）

> 功放，六根，再加喇叭两根。这一段最长，也最容易错。
>
> VIN 接 3V3，GND 接 GND。
>
> BCLK 接 GPIO5，LRC 接 GPIO4。
>
> 等一下——5 和 4 刚才不是麦克风用过了吗？
>
> 用过了。是共用的。
>
> 因为 C6 只有一路 I2S，收和发共用一个时钟。所以这两根线上会挂两个模块。这不是接错，它本来就这么设计。
>
> 然后是 DIN，接 GPIO7。这是唯一一根功放独享的线。
>
> 最后一根，最容易错：SD。这个 SD 是静音开关，必须硬接 3V3。
>
> 要是接 GPIO21 会怎样？GPIO21 是说话键。你一按键，功放就静音——你按着说话，它一声不吭。
>
> 喇叭两根，SPK+ 和 SPK−，随便接。接反了只是相位反，你听不出来。

（这根 `SD` 接上 3V3 时，从侧面拍，让引脚和排针在同一个画面里）

---

## [02:52] 段6 · 上电前自检（20 秒）

（万用表真的开机，表笔真的搭上去）

> 插电之前，六条，对一遍。
>
> 屏是四脚的不是七针的。SDA 在 11、SCL 在 10。功放的 SD 接的是 3V3。所有 GND 都回到板子的 GND。3V3 和 5V 没有短在一起。
>
> 最后一条别省——万用表量 3V3 和 GND。不通，才是对的。
>
> 要是通的，插上 USB 那几秒钟，就够把板子烧了。

（可以留一次真实的读数停顿，甚至说一句"呃，这个数不对，我再量一次"——真实感优先）

---

## [03:12] 段7 · 通电（18 秒）

> 插上 USB。
>
> 屏大概要等三秒才亮。别慌，它本来就慢。
>
> 然后用小智的微信小程序配一次网，之后它就自己连了。
>
> 现在，跟它说句话——

（停 2 秒，等它真的回话。**不要剪掉等待**，这段等待就是产品感）

> 就这样。五个零件，一根代码没写。

（收在屏上，不要加"下集见"）

## 中英术语对照（英文版直接吃这张表）

> 出英文版时，术语不能每次现想。这张表定下来，英文稿照这张表写，观众跨集才学得稳。

| 中文 | 英文 | 说明 |
|---|---|---|
| 面包板 | breadboard | |
| 凹槽 / 中间那条沟 | the center groove（口播可用 "that groove down the middle"） | 不用 channel，太专业 |
| 同一列五个孔相通 | five holes in a column are connected | |
| 杜邦线 | jumper wires | |
| 引脚 | pin | |
| 排针 | header pins | |
| 丝印 | the label printed on the board | 英文口语里不用 silkscreen，太工程 |
| 数字麦克风 | digital microphone | |
| 功放 | amplifier | |
| 喇叭 | speaker | |
| 静音脚 / 关断脚 | shutdown pin | |
| 共用（引脚/时钟） | shared | "these two pins are shared" |
| 短接 / 短路 | short（动词：short it out） | |
| 万用表 | multimeter | |
| 配网 | Wi-Fi provisioning（口语也可 "set up the Wi-Fi"） | |
| 唤醒词 | wake word | |
| 接触不良 | a loose connection | |
| 插实 | push it in all the way / seat it properly | |

**英文版要复用的三类句式**（中文稿里已经埋好了）：

| 中文原意 | 英文句式 |
|---|---|
| 这两根好说 | "These two are easy." |
| 坑在这两根 | "The trap is these two." |
| 插反了不会报错，就是黑屏 | "Wire it backwards and nothing complains — it just stays black." |
| 这不是接错，它本来就这么设计 | "That's not a mistake — it's how the board is designed." |
| 我知道你在想什么——是不是反了 | "I know what you're thinking — aren't these swapped?" |
| 别省这一条 | "Don't skip this one." |

## 录制提醒

- **别念稿**。记住每一段的"一个坑"，其他用自己的话说。念稿会把同伴感念成播音腔。
- **语速再慢 10%**。接线是给手做参考的，说快了观众跟不上手。
- **说错就接着说**，不要整段重录。这一集允许一次 NG 留在成片里。
- **不要在段间加"接下来我们"**。直接跳到下一件事，剪辑会处理过渡。
- **数字念清楚**：11、10、5、4、6、7、3V3。这一集全靠数字，念混一个整段就废了。
